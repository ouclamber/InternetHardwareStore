# 🖥️ HardWare Store — Интернет-магазин техники

Магазин, где можно купить **ноутбуки, компьютеры, смартфоны, телевизоры и колонки**.
Простой и удобный сайт: выбирай товары, добавляй в корзину, оформляй заказ — всё онлайн.

---

## 🛍️ Что можно делать на сайте

### 🏠 Главная страница
На главной — **5 категорий товаров**:
- 💻 **Ноутбуки**
- 🖥️ **Компьютеры**
- 📱 **Смартфоны**
- 📺 **Телевизоры**
- 🔊 **Колонки**

Кликни на категорию — откроется каталог с товарами.

### 📦 Каталог товаров
**50 товаров** с фотографиями, ценой и описанием:
- **Apple** MacBook, iPhone
- **Samsung** Galaxy, телевизоры QLED
- **Sony** Xperia, PlayStation, наушники
- **Xiaomi** RedmiBook, смартфоны
- **ASUS, Lenovo, HP, Dell, MSI** — ноутбуки и ПК
- **JBL, Sennheiser** — колонки

**Что можно:**
- 👀 Посмотреть фото и характеристики
- 🔍 Найти товар через поиск
- 📊 Отсортировать по цене или названию
- 🎯 Отфильтровать по категории

### 📱 Карточка товара
Кликни на товар — увидишь:
- **Большое фото**
- **Бренд** (Apple, Samsung, Sony...)
- **Цену** в рублях
- **Описание** с характеристиками
- Кнопку **«Добавить в корзину»**

### 🛒 Корзина
- **Список выбранных товаров** с картинками
- **Изменение количества** — кнопки `+` и `−`
- **Удаление** товара из корзины
- **Итоговая сумма** — с учётом доставки
- **Очистить корзину** — одной кнопкой

### 💳 Оформление заказа
Заказ оформляется **в 5 шагов**:

1. **Контакты** — имя, фамилия, email, телефон
2. **Адрес доставки** — город, улица, индекс
3. **Способ оплаты** — картой или наличными
4. **Данные карты** — номер, срок действия, CVV
5. **Подтверждение** — проверка заказа

После оформления — **заказ создан**, корзина **очищается**, товары **ждут доставки**.

### ⭐ Отзывы
- **Оценка товара** — от 1 до 5 звёзд
- **Комментарий** — напиши, что думаешь
- **Модерация** — отзыв публикуется после проверки

### 👤 Личный кабинет
- **Мои заказы** — история покупок
- **Статусы заказов** — оплачен, отправлен, доставлен
- **Смена пароля**
- **Регистрация и вход**

### 🔐 Админ-панель
*Доступна только администратору.*
- **Статистика** — сколько товаров, заказов, пользователей
- **Управление пользователями** — роли, удаление
- **Все заказы** — просмотр и смена статуса
- **Модерация отзывов**
- **Управление товарами**

## 🚀 Как запустить

### Что нужно установить

**1. Docker Desktop** — [скачать](https://www.docker.com/products/docker-desktop/)
Нужен для запуска серверной части и базы данных.

**2. Node.js 20+** — [скачать](https://nodejs.org/)
Нужен для запуска сайта (фронтенда).

После установки **перезагрузи компьютер** и проверь, что всё работает:

```bash
docker --version
node --version
npm --version
docker-compose up --build -d
npm start
